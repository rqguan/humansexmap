## 功能介绍

- 🗺️ **互动地图** — 像谷歌地图一样缩放与平移
- 🔵 **状态标注** — 点击任意词条循环切换五种状态（未选择 / 讨厌 / 可以尝试 / 喜欢 / 非常喜欢）
- 🔗 **一键分享** — 所有选择压缩编码进 URL，生成专属链接，无需登录，无需服务器
- 🌏 **Chrome 翻译友好** — 全部文字为真实 HTML 文本，浏览器内置翻译可直接使用
- 📱 **移动端支持** — 双指缩放 / 单指平移

## 使用方法

1. 打开页面，全图尽收眼底
2. **缩小**看大区全貌，**放大**查看子区词条
3. **点击词条**循环切换颜色状态，圆点代表你的偏好
4. 点击底部「**🔗 分享我的地图**」，复制专属链接发给对方
5. 对方打开链接，即可看到你的标注结果

### 状态颜色说明

| 圆点颜色 | 含义 |
|---------|------|
| ⚫ 灰色 | 未选择 |
| 🔴 红色 | 讨厌 |
| 🟡 黄色 | 可以尝试 |
| 🟢 绿色 | 喜欢 |
| 🟣 紫色 | 非常喜欢 |
